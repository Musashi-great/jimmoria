Current implementation policy:

- JIMMORIA is public-web first.
- Telegram and Discord connectors are not required and are not part of the default connector stack.
- Research should use web search, URL fetch, websites, docs, GitHub, X optional API, RootData optional API, explorer/RPC optional read-only checks, DEX Screener, CoinGecko, and RSS/public feeds.
